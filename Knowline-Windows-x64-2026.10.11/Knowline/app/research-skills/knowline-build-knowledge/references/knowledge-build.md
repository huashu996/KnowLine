# 构建分层知识与检索库

读取用户资料范围、输出位置和每层主题与侧重点；已有任务从冻结 context 读取，不重复创建。用户只需大致描述重点，无需技术 schema。任意层数与学科均可，不强加 SLAM 三层，不把 incoming/inputs 或页码当知识层。知序支持1–12层。

只读参考库 README、知识样本、证据注册与检索评测说明，提炼适用规则。读 [内容与排版](references/content.md)；知序任务另读 [交接合同](references/knowline.md)。已核查实物和一手资料见 [构建依据](references/evidence.md)，历史统计不是此次结果。

先准备可定位全文，再由 Codex 理解概念、假设、问题、机制、贡献和实验边界，形成符合用户重点的知识单元与主题导航。抽取/OCR/分块仅用于定位，不得把摘句填入通用标题冒充分析。深度以内容决定，不规定卡片数量或故意拖长执行时间。缺乏证据的公式、数字、书目与创新性保持未知。

知识单元保留稳定ID、用户层、语义主题、适用条件、局限和冻结来源。区分 source_fact/synthesis/inference/research_idea；推断与设想也给动机来源，不声称为论文事实。公式视觉核验后才标 verified；否则候选/待核验。关系说明概念依赖、方法差异、假设冲突或问题与方案联系；不强制所有层彼此关联。

索引整理后的知识内容、上下文、术语与证据，原文索引作为明确区别的辅助入口。使用可用本地关键词与真实学习式向量混合召回、有限显式关系扩展和排名融合；模型不可用时明确降级，哈希向量不能冒充语义模型。内容规范化哈希+实际模型ID控制去重和增量复用。查询知识不需要再次扫描PDF。

用用户相关的中英问题、方法问题、跨材料问题和无证据问题验证召回；命中不证明事实正确。提交覆盖与限制报告、可阅读分层文档、检索与关系成果及真实哈希。仅在内容、来源、选层与检索校验后完成；失败保留阶段文件和真实状态。原库、原资料与未授权成果不改写。

构建效率、失败恢复和真实计时执行 [高效完整构建合同](references/performance.md)。优先单一分析源和确定性渲染，不为速度减少完整来源、层、证据或检索验收；冷热复用分别报告。
