# 从 paper-agent 提取的知序验收合同

本文件是随知序提供的便携学术成果合同，重点为任务路由、协作审查、Word/公式和 PowerPoint 验收。已安装兼容 paper-agent 技能时可进一步复用；运行不依赖原作者电脑的技能路径。只适用于用户当前授权任务。

## 共同流程与证据

Planner → Executor → Reviewer 是同一执行器的三个顺序阶段，不默认启动子智能体。先冻结资料版本、哈希、选择页/区域、目标文件和用户参数，再执行；Reviewer 从最终保存状态查看可见结果，结构校验不能代替渲染审查。新图以冻结参考截图作为骨架。保留原始数据、文字、符号、引文、源图和已确认对象，不编造缺失项或用占位符冒充成品。

检索保留真实来源、取得时间和身份依据；题名相似不证明预印本与正式版关联。文件、正式引用和下载状态分别核验。论文关系必须有可追溯证据，推断与论文原有结论分开；搜索命中和引用次数不能证明引文方向。真实成果必须有文件哈希，并经知序单写者 API 校验回流。

## 正文与公式

- 按源截图顺序识别正文、内联变量和独立公式。无法辨认的位置说明缺项，不自行补公式、符号或推导。
- 正文、标题、图题、表题、注释、编号公式、数据表和参考文献按语义分别排版；正文中以“图/表”开头的引用句仍是正文。
- Word 正文两端对齐；标题与下段同页。学校/期刊、字体字号、纸张、方向、页边距和段距一经确认持续继承。未指定某学校规范时不能声称已符合该校完整模板。
- 公式使用 OMML 或 PowerPoint 非空原生 MathZone；用户明确选择 MathType 才用对应对象。普通文本下划线、公式图片、空 OLE 或空 MathZone 不能冒充原生公式。
- 上下标、分子分母、集合与矩阵结构按原文保留；函数和说明文字正体。不得用连续空格或制表符填充数学内容，编号位于独立区域；长公式按语义显式分行。
- 同时检查独立公式、正文内联变量和表内数学符号；空分子/分母、空上下标、空 sPre、替代字符、虚框、不可编辑伪公式必须为零。有意缺少的积分上下限显式隐藏。
- 不遍历全部表格统一美化。只对经语义分类的数据表应用三线表，编号公式和图表布局容器保持无边框；未授权对象保持原样。
- 最终保存后原生打开、回读真实公式数和结构，验证真实粘贴，再渲染并检查文字顺序、换行、编号、裁切、越界和空白。

## 科研图复刻

- 唯一目标为冻结任务 output_dir 内的 PPTX。不得读取、激活、修改、保存、关闭用户其他演示文稿，不调用 Application.Quit 或全局杀 Office 进程。
- 参考图逐对象保留文字、形状、颜色、拓扑、相对位置及比例。页面比例、主图体比例和模块比例分别冻结；只允许已授权的等比缩放和平移，不能拉伸填满页面。
- 有框模块的文字写入原生 shape；无框文字独立。直线/折线使用单个原生连接器并连接真实锚点；曲线使用已验证的单个原生自由曲线。复杂照片和场景裁剪为独立图片。禁止整张截图作为成品背景冒充复刻。
- 用户提供可直接使用的素材优先原样复用，不自行近似重画。文字、公式和关系逐项对应原图/正文，不添加正文未定义的实体或符号。
- 先共轴后连线。实心箭头按源图保留，普通 0.9–1.3 pt 细线采用相称的窄短箭头；从最终渲染检查目标端方向、线头比例及穿字。
- 同级子框、组内箭头和跨模块箭头分别保持一致的语义颜色及规格。字体字号依源图/用户合同；参数冲突时先明确冲突，不能为塞字静默缩小、放大或改变比例。
- 建立对象、Unicode 文字、连接器、颜色/填充账本及适用原生审计清单。源图没有某类对象时标记不适用，不用空数组真空通过本应执行的审计。
- 普通框中文字到四边至少 0.5× 字号安全距离；检查实际行数、可用宽高、孤字、溢出、碰撞、图层遮挡和箭头。标签字符上限不误用于图题和正文。
- 从最终 PPTX 原生打开、回读对象、非空 MathZone 并渲染。首次完整文件一次合并审查，真实问题集中修正后定向复查。没有查看最终预览不得填写 passed。

知序应分别显示“等待执行”“处理中”“成果校验失败”“真实通过/部分完成”；创建任务、工具探测、XML 有效和结构计数都不能代替实际功能验收。
