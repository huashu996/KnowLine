# 代码导入

资源库的“导入资源”支持切换“论文 PDF”和“代码文件 / 项目目录”；领域的“代码”入口默认选择代码类型并预选当前领域。

代码源文件支持多选，每个文件作为独立代码资源。项目目录作为一份代码资源，保留项目根目录和子目录路径。上传只读取用户在文件选择器明确选择的文件，不让服务读取任意电脑路径。来源保持原位。

代码内容保存为稳定的只读 ZIP 版本，复用已有代码树、阅读、行号批注、任务证据和知识库索引。相同文件名及内容/相同项目路径及内容去重；重复资源可加入新领域。项目元数据记录原名称、导入方式、文件数和跳过数。领域成员关联和目录发布均使用现有单写事务。

项目保留常见源码、说明和配置；依赖目录、控制配置、密钥、二进制、非代码资产和空目录不导入。支持源码扩展名见 backend/code_import.py。上传最多 128 MB，单个源码最多 16 MB，最多 10000 个文件；现有阅读器的单文件预览上限仍是 2 MB。非 UTF-8 文本可在阅读器选择 GB18030 或 Latin-1。

实现文件：frontend/src/ImportPicker.tsx、codeImport.ts、api.ts、App.tsx、i18n.tsx；backend/app.py、code_import.py。代码导入按本项目公共写入流程执行。

验证：tests/code-import-api.py 覆盖六种常见语言、空文件、目录结构、领域归属、去重、不安全输入、PDF 原字节回归、知识索引和重新打开后的持久化。tests/code-import-ui.mjs 覆盖资源目录选择、领域源码选择、代码阅读、中文路径和 PDF 选择器，支持 KL_CODE_TEST_EXE 指定安装包。验收摘要统一保存于 docs/compact-release.json。

精简版保留代码导入、高对比度阅读、Ctrl+滚轮字号、方案迭代与同会话来源核验；旧资料和构建目录在本次空版交付中清除。
