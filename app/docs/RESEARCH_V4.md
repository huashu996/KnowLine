# 原文证据到最小实验（v4）

优化构建流程，10篇常规论文约30分钟仅作效率参考，按真实内容与验收结果完成，不设置任务或阶段限时。优先复用短引文目录、分批检查点和已验证分析，不能把复用用时当冷构建成绩。

双路各保留最多60个候选，真实重排后默认最多40个排序结果；最后按每卡最多两个不同片段、每原文父上下文一次控制重复。最多展开8个已有一跳关联卡和24个被引原文上下文，额外上下文明确标记来源路径，不伪称相似度命中。卡片的双语术语进入受长度控制的语义上下文。原文事实检索中知识卡用于导航；独立知识库方案允许直接引用所选卡片内容，并明确原文是否经过本轮核验。设想不作事实证明。验收题与独立题都使用同一检索流程，不按标准答案补召回。

新构建和方案任务在创建时冻结 evidence-to-experiment-v4 合同；既有历史任务保持原合同。构建按用户层组织，卡片可有多个 layer_ids。每条主张绑定原文证据，方法卡记录前提、接口、失败与实现定位，未知为 null/unknown。论文声称、代码存在、冻结日志报告通过三种证据分开，结构验收不会证明科学结论。

索引保存独立 original-source parents 与 card/claim parents，在一个SQLite文件中建立两类可区分召回单元。原文按物理页/函数保留全文，小窗口用于BM25与向量召回；命中返回父上下文，evidence/{unit_id} 还可展开相邻页。事实检索在召回及关联扩展前排除 inference/research_idea；purpose=inspiration 才召回设想。不同主张/窗口不按卡片提前去重，独立来源按已验证 DOI 或资源ID计数。

保留BGE、BM25和RRF。模型文件版本、tokenizer哈希、查询与文档指令、pooling、维数、切块与词法规则共同决定向量复用。模型身份变化则关键词回退并要求重建；不混用旧向量。可安装可信本地ONNX cross-encoder参与RRF后的候选重排；未安装时返回 reranker.status=not_available。Qwen3生成式重排需要其兼容运行时与官方yes/no打分适配，不作为ONNX分类器直接加载。本次没有安装或对比Qwen权重。

方案通过 POST /api/v1/jobs/{id}/research-search 在冻结范围内检索，单次1–4题、最多3轮12题。四路为 similar_problem/mechanism/counterevidence/code；补检索需说明gap，后台保存可信索引身份和检索轨迹，任务目录的可编辑清单不具有授权效力。产物必须保留2–3个不同候选、接口检查、最近工作逐维比较、反证和最小实验。查新范围固定 selected_sources；完整外部查新需要另外取得可核验来源，不能借此宣称全球首创。

最小实验包含baseline、数据/划分、指标/预算、对照消融、失败条件、继续停止阈值和第一步。兼容性未知不能标compatible，选择已知不兼容方案会被拒绝。来源更新后，知识状态返回受影响卡片/主张；方案返回 needs_revalidation。历史证据不覆写。

验收为30–50个实际科研问题，每题检查所有要求的原文来源及卡片。无答案题还需要答案拒答审阅。平台记录时延、模型状态及调用数，答案支持度、冲突处理与实验可执行性需真实答案和研究者评审，不能以结构检查或mock测试替代。构建和方案技能分别提供完整字段说明。

参考设计：[RAPTOR](https://arxiv.org/abs/2401.18059)、[Qwen3官方实现](https://github.com/QwenLM/Qwen3-Embedding)、[Co-Scientist](https://www.nature.com/articles/s41586-026-10644-y)、[Ideation–Execution Gap](https://arxiv.org/abs/2506.20803)、[GraphRAG检索说明](https://microsoft.github.io/graphrag/query/overview/)。本实现未照搬层级摘要或全量GraphRAG，也未将这些研究结论当成本项目实测结果。

已发布知识可通过 POST /api/v1/knowledge-bases/{id}/refresh-retrieval 携带当前 base_revision 和 operation_id 重建检索；平台重新验证分析、产物哈希、原文与全部问题，成功后才切换索引，不重新调用模型撰写卡片，也不改变原分析合同。构建发布失败后的重试同样可核验并复用本任务保存的完整清单。

科研方案可仅选择知识库，不隐式选择其原始论文。创建时从已保存知识卡冻结独立快照；原资料缺失或变化时保留 source_review_required 和来源待复核信息，仍能基于明确版本的知识内容提出方案。纯知识库检索使用一次构建、按快照指纹复用的 FTS5/BM25 索引，可选本地重排只处理最多60个候选；同时选择原始资料时保留原文混合检索并合并两路结果。返回完整卡片上下文和 frozen_knowledge_card 引用，不伪造 PDF 资源。

知识卡引用核对任务选择的知识库版本、快照哈希、卡片哈希、摘录及来源身份；同一 DOI/来源文档的不同卡片不重复计数。知识内容核验不代表原论文、源码或实验已重新核验。Word/PPT、候选、反证、接口、最近工作及历史失败记录共用这一规则。POST /api/v1/jobs/{id}/audit-proposal 可在没有运行中的任务租约时重放原查询、核对原产物并重新回流，不调用智能体重新生成。
